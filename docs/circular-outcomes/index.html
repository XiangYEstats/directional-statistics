Bayesian research / Circular response

Regression with a circular response

When the response is an angle, a regression model needs to respect the circle. For example, the outcome may be wind direction, while covariates and latent effects describe how that direction changes.

THE RESEARCH

Link-adjusted von Mises distribution

The link-adjusted von Mises (LAvM) distribution transforms a centred von Mises variable through a link adjustment. Its linear-scale parameter η changes both the location and shape of the circular density, while κ controls concentration in the underlying von Mises distribution. This provides a distributional basis for regression with a circular response; the accompanying tutorial develops its implementation in Stan.
